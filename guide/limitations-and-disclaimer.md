# Limitations and Engineering Disclaimer

## Known Limitations

### 1. 2D Plane Strain Assumption
- ADONIS is a **2D plane strain** program only
- Cannot model 3D effects (tunnel face effects, 3D stress redistribution)
- Out-of-plane strain is assumed zero
- Results are per unit thickness (typically 1m)

### 2. Material Models
Limited to 8 built-in constitutive models:
- IsoElastic (linear elastic)
- Mohr-Coulomb (elastic-perfectly plastic)
- Hoek-Brown (rock mass)
- Modified Hoek-Brown (with tension cut-off)
- Cam-Clay (soft clay)
- Strain-Softening (post-peak behavior)
- P-Hardening (stress-dependent stiffness)
- Ubiquitous-Joint (jointed rock)

**Custom models** require C++ DLL development (User-Defined Constitutive Model).

### 3. Groundwater Modeling
- Simplified water table (horizontal or inclined)
- **No coupled flow-deformation analysis**
- Pore pressure is calculated from water table position only
- No transient seepage analysis
- No consolidation analysis

### 4. Structural Elements
Supported elements:
- Beam (bending + axial)
- Liner (beam with interface on both sides)
- Cable (axial only, with grout bonding)
- Tieback / grouted anchor (explicit pretension command is not covered by this skill)
- Strip (reinforcement strips)

**Not supported:**
- Complex structural systems (frames, shells)
- Contact elements between structural components
- Time-dependent structural behavior (creep, relaxation)

### 5. Analysis Types
**Supported:**
- Static equilibrium (gravity loading, surcharge)
- Factor of Safety (Strength Reduction Method)
- Sequential construction (excavation, backfill, support installation)
- Stress relaxation (tunnel excavation simulation)

**Not covered by this skill:**
- Dynamic/seismic analysis
- Transient analysis
- Coupled thermo-mechanical analysis
- Large deformation analysis

### 6. Mesh Limitations
- Element types: T3 (3-node triangle), Q4 (4-node quad), T6 (6-node triangle)
- No automatic mesh refinement during analysis
- No adaptive meshing
- Mesh quality affects accuracy (aspect ratio, skewness)

### 7. Boundary Conditions
- Standard fixities: xfix, yfix, xyfix
- Velocity/force/stress boundary conditions
- No infinite elements or absorbing boundaries
- No periodic boundary conditions

### 8. Solver Limitations
- Explicit finite difference solver (dynamic relaxation to static equilibrium)
- Convergence depends on damping ratio and step limit
- No implicit solver available
- No nonlinear solver options (Newton-Raphson, etc.)

## Engineering Disclaimer

### ⚠️ CRITICAL WARNING

**Scripts generated by this skill are for PRELIMINARY ANALYSIS AND PROTOTYPING ONLY.**

They are **NOT SUITABLE** for:

1. **Final Design Verification**
   - Do not use generated scripts for final design calculations
   - All designs must be verified by qualified engineers using site-specific data

2. **Tender Design**
   - Do not use for contract documents or tender submissions
   - Tender designs require detailed geotechnical investigation

3. **Claim Assessment**
   - Do not use for dispute resolution or claim evaluation
   - Claims require forensic engineering analysis with actual site data

4. **Safety-Critical Decisions**
   - Do not use for decisions affecting public safety
   - Safety assessments require comprehensive analysis and peer review

5. **Regulatory Submissions**
   - Do not use for permits or regulatory approvals
   - Regulatory submissions require certified engineering calculations

### Required Professional Practice

Before using any generated script for professional work:

1. **Review by Qualified Engineer**
   - All scripts must be reviewed by a licensed geotechnical engineer
   - Engineer must verify all assumptions, parameters, and boundary conditions

2. **Site-Specific Data**
   - Replace typical material properties with site-specific test results
   - Use actual soil/rock parameters from geotechnical investigation
   - Validate groundwater conditions with field measurements

3. **Model Validation**
   - Compare results with hand calculations or closed-form solutions
   - Perform sensitivity analysis on key parameters
   - Validate against field measurements if available

4. **Documentation**
   - Document all assumptions and simplifications
   - Record all input parameters and their sources
   - Maintain version control of all scripts

5. **Peer Review**
   - Critical analyses should undergo independent peer review
   - Complex models should be verified by second engineer
